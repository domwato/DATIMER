The first public release of DA Timer: a segment and program timer for broadcast Director's Assistants, with a second-screen output for presenters and floor.

## Download

| Computer | File |
| --- | --- |
| Windows 10/11 (64-bit) | **DA-Timer-windows.zip**: DA_Timer.exe, help PDF and Stream Deck plugin |
| Mac with Apple silicon (M1 and later) | **DA-Timer-mac-apple-silicon.zip** |
| Older Intel Mac | **DA-Timer-mac-intel.zip** |

The apps aren't signed, so Windows SmartScreen and macOS will warn the first time you open them:
- **Windows:** click "More info", then "Run anyway".
- **Mac:** System Settings → Privacy & Security → **Open Anyway**.

See `DA Timer Help.pdf` for how to use it.

## What's in 1.0

- **Clocks:** segment and program clocks with ALL START / ALL STOP, NEXT, PRESET (even while running) and RESET with undo.
- **Running order:** segment goals, over/under per segment and in total, segments in show and "segments left".
- **Back-timing:** to a hard out, either an off-air time or a program length.
- **Log:** notes and marks stamped with time of day and program time, exported to Excel.
- **Output screen:** set the layout, sizes, colours and order per show. The segment clock can count down, and you can add a time of day or LTC timecode clock.
- **Time source:** the PC clock, NTP or LTC timecode.
- **Stream Deck:** direct USB control, or through the Elgato plugin.
- **Settings:** switch features off, choose fonts and the interface size. Works on 4K and Surface screens.
- **Show safety:** keeps the computer awake while running, recovers after a crash, and hides the mouse on the output.
